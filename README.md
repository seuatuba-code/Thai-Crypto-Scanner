# Thai Crypto Scanner Android
โปรเจกต์ Android สำหรับจำลองส่วนต่างราคา ไม่ส่งคำสั่งซื้อขายจริง
สร้าง repository บน GitHub แล้วอัปโหลดทุกไฟล์รวม .github/workflows/build.yml โดยรักษาโครงสร้างโฟลเดอร์ (ต้องใช้ Git client หรือ editor ที่สร้างโฟลเดอร์ได้) เปิด Actions > Build Android APK > Run workflow และดาวน์โหลด artifact เมื่อ build สำเร็จ แตก ZIP แล้วติดตั้ง app-debug.apk เฉพาะบนเครื่องของคุณเอง
สแกนทุก 60 วินาทีเฉพาะขณะเปิดหน้าจอแอป ค่าธรรมเนียมเป็นสมมติฐาน API ยังไม่ได้ทดสอบจริง และยังไม่ได้ compile ในสภาพแวดล้อมนี้ ไม่มีการแจ้งเตือนเบื้องหลัง ไม่มีการรับประกันกำไร
